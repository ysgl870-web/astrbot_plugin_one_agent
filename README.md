## 安装

将插件目录放入 AstrBot 的 `data/plugins/` 下，然后在 WebUI 中重载插件。

插件目录内至少包含：

- `main.py`
- `_conf_schema.json`
- `metadata.yaml`
- `README.md`

不依赖第三方 Python 包。
