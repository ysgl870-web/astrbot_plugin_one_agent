# astrbot_plugin_one_agent · 待办事项与提醒 2.1.0

这是一个面向 AstrBot 的待办管理插件。

## 指令

| 指令 | 说明 |
|---|---|
| `待办/代办 <内容> [高/中/低]` | 添加待办 |
| `待办列表` | 查看全部 |
| `待办列表 未完成` | 只看未完成 |
| `待办列表 已完成` | 只看已完成 |
| `完成 1` | 完成当前列表第 1 项 |
| `完成 #7` | 精确完成 ID=7 |
| `撤销完成 1` | 恢复未完成 |
| `编辑 1 新内容` | 修改内容 |
| `优先级 1 高` | 修改优先级 |
| `截止 1 2026-10-06 18:00` | 设置截止时间 |
| `提醒 1 30分钟` | 设置单项提醒 |
| `取消提醒 1` | 取消单项提醒 |
| `今日待办` | 查看今天相关待办 |
| `逾期待办` | 查看逾期未完成任务 |
| `我的待办` | 查看自己创建/认领的任务 |
| `搜索待办 关键词` | 搜索任务 |
| `完成率` | 完成率 |
| `待办统计` | 汇总统计 |
| `自助代办` | 认领一项未认领任务 |
| `放弃代办 1` | 放弃认领 |
| `删除 1` | 删除任务 |
| `清空待办` | 发起清空确认 |
| `确认清空` | 60 秒内确认清空 |
| `每日提醒 18:00` | 开启每日提醒 |
| `取消每日提醒` | 关闭每日提醒 |
| `代办菜单` | 查看帮助 |
| `管理设置` | 查看当前设置 |

## 数据

持久化数据存放于 AstrBot 的插件数据目录，不写入插件代码目录，避免更新插件时覆盖用户数据。旧版 JSON 数据会自动迁移。

## 开发规范

本插件按照 AstrBot 新插件开发文档的基础约定编写：使用 `metadata.yaml` 作为插件元数据；持久化使用插件数据目录；网络功能如未来扩展应使用异步 HTTP 客户端而不是 `requests`。
